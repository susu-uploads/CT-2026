# Облачные технологии

- **Учебный год:** 2026/2027, очная форма.

## Преподаватели

Глеб Игоревич Радченко — ведущий преподаватель, доцент кафедры системного программирования, к.ф.-м.н.; Амир Басим Абдуламир Алаасам — ассистент, доцент кафедры системного программирования, к.ф.-м.н.

## Формат оценки

Экзамен в форме теста или автомат по текущей успеваемости и бонусам. Текущий контроль: практические работы — 80%, тесты на лекциях — 20%.

1. Введение в облачные вычисления
2. Публичные облака
3. Контейнеры Docker
4. Многоконтейнерные окружения
5. Docker Swarm
