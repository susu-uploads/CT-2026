Цель: самостоятельно развернуть LAMP и WordPress на публичной виртуальной машине, показать удаленное управление с macOS и подготовить отчет.

## Подготовка со стороны студента

- [x] Зарегистрироваться у облачного провайдера и подключить оплату. Используется HOSTKEY; создание VPS выполнено студентом.
- [x] Заказать чистую VPS: Ubuntu 24.04 LTS, x86_64, 2 vCPU, 2 ГБ RAM, от 20 ГБ диска, публичный IPv4. Не заказывать готовый WordPress или панель управления.
- [x] Добавить публичный SSH-ключ с Mac на сервер. Приватный ключ хранить локально, не отправлять в чат и не добавлять в Git.
- [x] Передать агенту IP, SSH-порт, имя пользователя с root/sudo и локальный путь к приватному ключу. Доступы и адрес сервера в этот файл не записывать.
- [ ] Сохранить скриншот созданной VM в кабинете провайдера без платежных данных и секретов.

## Критерии готовности и ограничения

- SSH с Mac работает по ключу; Apache и MySQL запускаются автоматически.
- PHP выполняется, приложение подключается к БД, WordPress показывает тестовую публикацию из внешней сети.
- После перезагрузки сервер сохраняет работоспособность; отчет содержит собственные доказательства выполнения.
- Домен, Docker, плагины WordPress и автоматизация развертывания в базовый объем не входят.
- По сохраненному TASK.md техническая часть дает до 18 баллов; после 11 октября бонус за срок равен 0. Фактическую оценку выставляет преподаватель.
- Тариф, доступность выбранной ОС и текущее окружение сервера проверить перед выполнением. Работа оплачиваемых ресурсов может продолжать тарифицироваться после остановки VM.
