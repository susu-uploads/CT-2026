| **5\*** | **Разработать и показать масштабируемость собственного веб-приложения, обеспечивающего обработку CSV-файлов и реализующего их асинхронную (отложенную) обработку. Веб-сервис должен предоставлять веб-API, обеспечивающий загрузку в сервис таблицы в виде CSV-файла для ее обработки и получения результата в виде N элементов из данного файла с максимальным значением значения данных по определенному полю данного CSV-файла (TOP-N). Первая строка CSV-файла содержит заголовки соответствующих столбцов таблицы. В качестве примера можно использовать данные со страницы <https://www3.epa.gov/otaq/tcldata.htm> (например, <https://www3.epa.gov/fueleconomy/testcars/database/16tstcar.csv>).** | **5 \*** |
