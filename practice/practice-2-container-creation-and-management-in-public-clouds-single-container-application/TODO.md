## Облачный этап — после получения доступа

- [ ] Получить IP, SSH-порт, пользователя с root/sudo и локальный путь к приватному ключу. Ключ не отправлять в чат и не добавлять в Git.
- [ ] Настроить локальный SSH-алиас ct-vps и проверить подключение и ключ хоста.
- [ ] Проверить Ubuntu, x86_64, доступные ресурсы, занятость 8080 и существующие контейнеры. Сохранить Apache и WordPress практики 1 на порту 80.
- [ ] Собрать образ AMD64; сохранить через docker save в игнорируемый .cache/.
- [ ] Передать архив по SSH, сверить SHA-256 и загрузить через docker load. Registry не нужен.
- [ ] Установить Docker Engine по инструкции REPORT.md, если он отсутствует.
- [ ] Запустить контейнер на 8080 с --restart unless-stopped.
- [ ] Открыть TCP/8080 с учетом сетевых правил провайдера и Docker, сохранив доступ SSH и WordPress.
- [ ] Выполнить test_app.py с Mac по публичному IP, проверить форму и документацию API.
- [ ] Проверить восстановление после перезапуска Docker, предварительно убедившись в отсутствии чужих контейнеров.
- [ ] Проверить, что WordPress практики 1 продолжает работать.
