**Цель:** изучить принципы работы платформы Docker, методы создания контейнеров и
развертывания контейнеров в публичных облаках.

**Критерии
оценивания**

|  |  |  |
| --- | --- | --- |
| № | Задача | **Баллы** |
| 1\. | На локальном компьютере должна быть развернута инфраструктура Docker | 9 |
| 2\. | В рамках развернутой инфраструктуры Docker, должно быть развернут контейнер с тестовым веб-приложением, к которому должен быть обеспечен доступ с локального компьютера. | 9 |
| 3\. | Сдача в срок: задачи 1-2 сданы до 17 октября – 2 балла; с 17 по 31 октября – 1 балл; после 31 октября – 0 баллов. | 2 |
| **4\.** | **В публично-доступном облаке развернуть Docker-контейнер с тестовым веб-приложением. Необходимо продемонстрировать публичную доступность и процесс работы веб-приложения в облачной среде.** | **5\*** |
